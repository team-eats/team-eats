Conceptual Model

Entities and Attributes

Profile

  • Profile ID (primary key)
  • profile name
  • email address
  • password
  • is-business-owner
  • date-profile-created

Business

  • business id (primary key)
  • profile id (secondary key)
  • business name
  • banner photo
  • business profile photo
  • hours
  • bio
  • business email address
  • phone number

Like

  • liking user id (secondary key)
  • liked business id (secondary key)
  • timestamp

Location

  • location id (primary key)
  • business id (secondary key)
  • location of business
  • start timestamp
  • end timestamp

Menu Section

  • menu section id (primary key)
  • business id (secondary key)
  • section name

Menu Item

  • menu item id (primary key)
  • menu section id (secondary key)
  • item description
  • menu item photo
  • price

Relationships

Profile

  • one profile can manage many business listings (one to many)
  • one profile can like many listings (one to many)

Business

  • one business can be liked by many profiles (one to many)
  • one business can have many locations (one to many)
  • one business can have many menu sections (one to many)
